# Symptom index

One line per symptom in the [subsystem references](../reference/): what you see (an assertion, a `[RED]` line, an abort or crash site, a visible result) and the entry that explains it. Search this page for the text in your log first (`grep -i` the function name, the `[RED]` text or the address form), then read the entry and the game notes it names. For an Android run log, run `python3 dm/tools/log_digest.py <log>` first (it matches the log against this page and `dm/tools/log_rules.tsv` and prints the verdict, the crash and the grouped `[RED]` lines with their line numbers), `--filter` when you need the run's story without its routine lines, and read the raw log only around the line numbers they give. Generated by `dm/tools/docs_symptoms.py` from the entries' Symptom bullets: change the entry, then run it.
